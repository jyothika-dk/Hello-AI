# 🐍 Python Mini Projects Collection

A curated collection of interactive Python scripts, AI-powered tools, terminal games, and machine learning models built using popular libraries like `colorama`, `TextBlob`, `TensorFlow`, and `pandas`.

---

## 📂 Projects Included

### 1. Study Companion (Interactive Questionnaire)
* **File:** `study_companion.py`
* **Description:** A simple, interactive terminal script that greets the user and asks about their study preferences (day vs. night) with dynamic conditional responses.
* **Libraries:** Built-in Python features.

### 2. Chef's Recipe Critic (Sentiment Analyzer)
* **File:** `recipe_critic.py`
* **Description:** A text-analysis utility that evaluates user-inputted food reviews using natural language processing to categorize dishes into Five-Star, Average, or Disaster ratings.
* **Libraries:** `colorama`, `textblob`

### 3. FitBot CLI Assistant (Fitness Chatbot)
* **File:** `fit_bot.py`
* **Description:** An interactive fitness coach assistant that provides workout recommendations (cardio, strength, flexibility), gear tips, and workout puns.
* **Libraries:** `re`, `random`, `colorama`

### 4. Grid Battle (Terminal Board Game)
* **File:** `grid_battle.py`
* **Description:** A strategic grid game against an AI opponent featuring smart blocking and winning logic, full input validation, and colored terminal tokens.
* **Libraries:** `random`, `colorama`

### 5. Fashion MNIST Classifier (Neural Network)
* **File:** `fashion_classifier.py`
* **Description:** A deep learning model built with TensorFlow/Keras that loads the Fashion MNIST dataset, normalizes image data, trains a sequential neural network, evaluates test accuracy, and displays predictions.
* **Libraries:** `tensorflow`, `matplotlib`

### 6. Book Recommendation Assistant
* **File:** `book_recommender.py`
* **Description:** An intelligent recommendation system that analyzes your mood using sentiment analysis and filters bestseller book data based on genre and reader ratings.
* **Libraries:** `time`, `pandas`, `TextBlob`, `colorama`
